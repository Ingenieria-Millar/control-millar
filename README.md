### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/Ingenieria-Millar/control-millar.git
   ```
2. Navigate to the directory:
   ```bash
   cd control-millar
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the application:
   ```bash
   npm start
   ```
